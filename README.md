# 文件编辑器插件

在 DSH 桌面版里提供「打开、编辑、查看文件」能力的插件。功能口径仿照 OneEdit，但与 OneEdit 应用及其工程没有任何关系，运行时不依赖、不调用 OneEdit。

- 状态：验证一（装得上）进行中。
- 依据：`../docs/06-DSH桌面版编辑器插件设计.md`（设计）、`../docs/07-DSH桌面版编辑器插件执行计划.md`（执行计划）、`../docs/08-编辑器插件上手知识面.md`（上手知识面）。
- 目录：`index.js` 宿主半侧入口；`cordis.patch.yml` 安装后生效的插件行；`验证记录/` 每件验证一篇。
- 命名：机器要求的字段用英文（包名 `dsh-file-editor`、代码标识符），其余用中文。
- 硬约束：本插件自身不接触密钥、不直接调用模型接口；写盘只走宿主能力，不绕沙箱、不提权。
